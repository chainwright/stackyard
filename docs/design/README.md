# docs/design

## `reference-stamp-pad-tiles.png` is AI-generated

`reference-stamp-pad-tiles.png` is an **AI-generated concept image**. We used it
early on, as a mood reference, to choose the "Stamp Pad" direction (paper cards,
metal rings, coloured answer tiles, a red rubber stamp). It is **not a screenshot
of Stackyard**, no shipped UI is copied from it, and it should never be shown as
the product. The PNG still carries the generator's provenance metadata.

Everything else in this folder (`maker/*.html`, `maker/built/*.png`, `review/`)
is our own work: the HTML mockups, and screenshots of the built app.
