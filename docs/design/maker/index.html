Stackyard Maker design mockups

Maker screen mockups

Static reference mockups of every Maker screen state, drawn in the Stamp Pad design system. Each file is self-contained — inline CSS with self-hosted fonts in ./fonts, no external URLs — and shows the card drawn the same way the class sees it. These anchor the design review before any UI code is written.
